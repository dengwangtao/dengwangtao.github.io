雅思全科全题型保姆级备考指南（差基础·在职版）

更新日期：2026年9月20日
适用人群：英语基础较弱、在职、每天可投入30～90分钟，希望系统准备听力、阅读、写作和口语的考生。
学术类与培训类：听力和口语相同；阅读文章类型不同；写作 Task 1 不同。本文完整说明两种考试的差异。

一、怎么使用这份手册

不要从第一页一次性学到最后一页。正确用法是：

  1. 先完成一次四科诊断；

  2. 找出当前最弱的两个能力；

  3. 每周只集中突破少数题型；

  4. 每次练习都完成复盘；

  5. 基础稳定后再整套限时；

  6. 每周依据数据调整任务。

全科统一学习闭环：

学规则 → 看示范 → 慢速练习 → 找证据或评分问题 → 记录错因 → 隔天重做 → 限时练习

二、差基础先补什么

1. 四项底层能力

2. 不要等待基础全部补完

词汇、语法和题型应同步学习。建议初期比例：

  • 40%：词汇、语法、辨音等基础；

  • 40%：分题型慢练；

  • 20%：复盘和隔天重做。

3. 第一次诊断

使用未做过的官方样题或剑桥雅思真题：

  • 听力：完成一个 Section；

  • 阅读：完成一篇 Passage；

  • 写作：各写一篇提纲，任选一篇写全文；

  • 口语：录制 Part 1、Part 2、Part 3 各一题。

记录四类问题：不会、做错、来不及、不稳定。

三、全程备考路线

阶段一：基础搭建（第1～4周）

  • 不急于做完整套题；

  • 听力重点练填空、数字、日期、姓名和拼写；

  • 阅读从 Passage 1 开始，先找证据再提速；

  • 写作先练正确句子和段落，不急于背整篇模板；

  • 口语先保证能持续回答，再提升词汇和准确性。

阶段二：题型突破（第5～8周）

  • 每周集中训练2～3种题型；

  • 建立听力和阅读错题分类；

  • 写作按题型建立结构库；

  • 口语按话题建立个人素材库；

  • 开始单篇或单部分计时。

阶段三：组合训练（第9～12周）

  • 听力和阅读进行整套训练；

  • 写作在规定时间内完成 Task 1 和 Task 2；

  • 口语连续模拟三部分；

  • 统计正确率、用时和重复错误。

阶段四：考前稳定（最后2～3周）

  • 以完整模拟和错题回炉为主；

  • 不频繁更换资料和方法；

  • 固定考试流程、时间分配和检查清单；

  • 保持作息，避免考前突然增加学习量。

第一部分：听力 Listening

听力包含4个部分，共40题。训练重点包括：读题预测、辨音、同义替换、连续跟题和准确拼写。

四、听力通用做题流程

播放前

  1. 快速阅读题目和要求；

  2. 圈出关键词；

  3. 判断空格词性；

  4. 预测答案类型；

  5. 标记题目之间的切换信号。

预测示例：

  • price：可能听到数字和货币；

  • address：可能听到街道名称和门牌号；

  • reason：重点听 because、due to、so；

  • a/an 后：通常需要可数名词单数；

  • many 后：通常需要复数名词。

播放中

  1. 视线保持在当前题和下一题；

  2. 听到定位词后，等待真正答案；

  3. 警惕说话人改口；

  4. 漏掉一题立即放弃，继续跟下一题；

  5. 先记可识别缩写，结束后补全。

播放后

  1. 检查拼写；

  2. 检查单复数；

  3. 检查字数限制；

  4. 检查答案是否符合语法；

  5. 不凭印象随意修改。

五、听力各种题型

1. Form / Note / Table Completion（表格与笔记填空）

学习重点

  • 数字、日期、时间、价格、电话号码；

  • 姓名、地址和字母拼写；

  • 日常生活与校园场景词；

  • 单复数和词性判断。

做题流程

  1. 看标题，确认场景；

  2. 横向、纵向阅读表格；

  3. 根据空格前后预测答案；

  4. 听到定位词后等待同义表达；

  5. 按原话填写并检查字数。

常见陷阱

  • 说话人先给旧信息，随后修改；

  • 听到了数字但单位不对；

  • 漏写复数；

  • 地址、姓名拼写不完整；

  • 把例子写成答案。

复盘方法

重听前先看文本定位漏听位置；标出答案前的信号词、同义替换和改口表达；最后进行听写或跟读。

2. Sentence Completion（句子填空）

做题流程

  1. 先读完整句子；

  2. 判断空格词性和语义；

  3. 圈出不容易替换的名词；

  4. 听到相关句时关注改写；

  5. 检查填入后句子是否通顺。

常见错误是只听到原词就填写，却没有理解句子关系。

3. Summary / Flow-chart Completion（摘要与流程填空）

做题流程

  1. 先判断内容主题；

  2. 阅读流程方向和前后步骤；

  3. 标出 first、then、after、finally 等顺序信号；

  4. 预测每个空的词性；

  5. 听到过程变化时及时移动到下一题。

流程题最怕停留在上一空。漏听后应立即继续跟进。

4. Short-answer Questions（简答题）

做题流程

  1. 判断问题问人、地点、时间、原因还是数量；

  2. 圈出疑问词和核心名词；

  3. 预测可能的答案形式；

  4. 按字数限制记录；

  5. 检查是否回答了真正的问题。

5. Multiple Choice（单选与多选）

学习重点

  • 快速理解选项差异；

  • 识别同义替换；

  • 区分过程信息和最终决定；

  • 识别说话人的态度。

做题流程

  1. 先看题干，明确问题；

  2. 比较选项，圈出差异；

  3. 听时不追求每句话都懂；

  4. 对每个选项做支持、反对或未提及判断；

  5. 以最终表达为准。

常见陷阱

  • 三个选项都被提到；

  • 先赞成后否定；

  • 选项复用录音原词，但意思不对；

  • 多选题漏选或多选。

6. Matching（匹配题）

常见形式：人物与观点、地点与活动、项目与特征匹配。

做题流程

  1. 快速浏览全部选项；

  2. 给选项写一两个字的区别标签；

  3. 听到人物或项目名称后准备记录；

  4. 根据完整观点选择，不根据单个词；

  5. 检查选项是否可重复。

7. Plan / Map / Diagram Labelling（地图与图示题）

学习重点

  • 方位词：north、south、left、right；

  • 路线词：go past、turn、cross、at the end；

  • 位置词：opposite、next to、between、behind；

  • 起点和朝向。

做题流程

  1. 找到起点和方向；

  2. 浏览已有地点；

  3. 用笔或鼠标跟随路线；

  4. 每听到一次转向就更新位置；

  5. 迷路时找下一个已知地标重新进入。

六、听力基础提升与复盘

精听四步法

  1. 不看文本听一遍，写下能听到的内容；

  2. 分句重听，补充遗漏；

  3. 对照文本，标记生词、连读、弱读和同义替换；

  4. 跟读录音，模仿停顿和重音。

不要整篇逐字听写。优先精听错题附近30～60秒。

听力错题分类

每天45分钟听力方案

  • 10分钟：场景词和拼写；

  • 15分钟：完成一组题；

  • 15分钟：精听错题片段；

  • 5分钟：跟读和隔天复习。

第二部分：阅读 Reading

阅读训练的核心不是全文翻译，而是题目分析、定位、同义替换、局部精读和证据判断。

七、阅读通用做题流程

  1. 用约1分钟观察标题、段落和专有名词；

  2. 阅读当前题组要求；

  3. 圈出定位词并预测同义替换；

  4. 回原文扫读定位；

  5. 精读定位句和前后句；

  6. 根据证据作答；

  7. 检查字数、拼写和单复数。

基础阶段可以给一篇文章30～40分钟。能稳定找到证据后，再逐步缩短时间。

八、阅读各种题型

1. TRUE / FALSE / NOT GIVEN

  • TRUE：题目与原文事实一致；

  • FALSE：原文与题目明确相反；

  • NOT GIVEN：原文没有足够信息判断。

做题流程

  1. 拆出题目的主语、动作、对象和限定词；

  2. 找到原文对应信息；

  3. 比较时间、范围、数量、程度和因果；

  4. 不使用常识补充文章；

  5. 找不到证明或反驳时，考虑 NOT GIVEN。

高频陷阱

  • some 被改成 all；

  • may 被改成 must；

  • 原文只说相关，题目说因果；

  • 原文比较 A 和 B，题目改变比较方向；

  • 原文没有提到题目新增的对象或时间。

2. YES / NO / NOT GIVEN

判断作者观点，而不是客观事实。先确定是谁的观点，再看作者是否明确同意、反对或未表态。

重点标记表示态度的词：believe、argue、criticise、support、doubt、should、may。

3. Matching Headings（段落标题）

做题流程

  1. 浏览标题，写出每个标题的核心差异；

  2. 阅读一段的首句、末句和转折句；

  3. 用一句自己的话概括整段；

  4. 选择覆盖全段的标题；

  5. 排除只描述例子、人物或局部细节的标题。

标题题优先找段落功能：提出问题、解释原因、介绍变化、举例、反驳、提出方案或总结结果。

4. Matching Information（信息匹配）

做题流程

  1. 圈出题目中特殊且容易定位的信息；

  2. 预测可能的同义替换；

  3. 为各段写两三个字的主题标签；

  4. 在候选段落中找完整证据；

  5. 注意一个段落可能对应多个题目。

5. Matching Features（人物／理论／特征匹配）

先圈出所有人物、国家、年代或理论名称，在旁边记录核心观点；再用题目陈述匹配。注意区分某人自己的观点、别人对他的评价和研究结果。

6. Matching Sentence Endings（句尾匹配）

先读句子前半部分并定位，找到证据后用自己的话预测结尾，再查看选项。答案必须同时满足语法和原文意思。

7. Multiple Choice（单选与多选）

做题流程

  1. 判断问题问主旨、目的、原因、细节还是态度；

  2. 回原文定位；

  3. 不看选项，先概括可能答案；

  4. 对照选项逐一排除；

  5. 多选题确认要求选择几个答案。

干扰项常见方式：复用原词但意思错误、把部分信息扩大、混淆原因和结果、偷换人物、只有一半正确。

8. Sentence Completion（句子填空）

  1. 看字数限制；

  2. 根据空格前后预测词性；

  3. 用题目关键词定位；

  4. 从原文准确提取；

  5. 检查语法、拼写和单复数。

9. Summary / Note / Table Completion

先通读摘要或表格，判断主题；预测各空词性和含义；利用已有信息定位原文；最后通读答案，检查语法与逻辑。

如果题目要求从文章中选词，不要自行改写。若提供词库，则同时检查意思和语法。

10. Flow-chart Completion（流程图）

先确认起点、终点和步骤顺序；关注 first、after、before、subsequently、finally 等顺序表达；逐步回原文定位。

11. Diagram Label Completion（图示标注）

先看图形方向、部件和已有标签，再定位描述结构、位置或过程的段落。重点关注方位、组成和连接关系。

12. Short-answer Questions（简答题）

判断疑问词要求的人、时间、地点、原因或数量，定位后按字数限制提取最短且完整的答案。

九、阅读复盘流程

每道错题完成以下记录：

  1. 正确答案在原文哪一句；

  2. 题目和原文怎样同义替换；

  3. 第一次为什么定位错误；

  4. 哪个句子结构或逻辑没有读懂；

  5. 下次遇到同类问题怎样处理；

  6. 第二天能否独立重做正确。

阅读错误分类

每天60分钟阅读方案

  • 10分钟：复习真题词汇；

  • 25分钟：完成一个题组或半篇文章；

  • 20分钟：找证据、整理替换、拆难句；

  • 5分钟：重做昨天错题。

第三部分：写作 Writing

写作不能只背模板。稳定提高需要同时训练任务回应、结构、论证、词汇、语法和检查能力。

十、写作通用训练流程

每个题型依次经历：

  1. 阅读题目并识别任务；

  2. 5分钟内完成提纲；

  3. 先写单个段落；

  4. 再写完整文章；

  5. 按评分维度自查；

  6. 修改而不是只看范文；

  7. 隔几天重写同题。

基础阶段不要每天写完整作文。可以用“句子 → 段落 → 全文”的顺序提升。

十一、Academic Writing Task 1

Task 1 要求客观描述视觉信息。核心结构通常是：引言、概述、两个细节段。不要写个人观点，不要解释图表没有提供的原因。

通用四步

  1. 改写题目，说明图表内容；

  2. 找出2～4个最明显的总体特征；

  3. 合理分组，而不是逐项罗列；

  4. 用数字和比较支持特征。

1. Line Graph（折线图）

观察顺序

  • 总体上升、下降还是波动；

  • 起点和终点；

  • 最高点和最低点；

  • 交叉点；

  • 哪几条线走势相似。

写作流程

引言改写题目；概述写总体趋势；细节段按时间或走势分组；使用准确数据支持。

不要逐年报数字，也不要把 fluctuation 用于只有一次变化的数据。

2. Bar Chart（柱状图）

先找最高、最低、相近和差距最大的项目。项目多时按高低、地区、年份或相似模式分组。

避免按图表顺序机械罗列每一根柱子。

3. Pie Chart（饼图）

重点比较最大占比、最小占比、相近部分和比例变化。常用 fraction、proportion、account for、constitute 等表达，但准确性优先。

4. Table（表格）

先寻找最大值、最小值、共同趋势和异常项，再决定分组。表格数字多，不能全部写入，应选择能支持主要特征的数据。

5. Mixed Charts（混合图）

先判断两张图之间是什么关系，再分别找各自主要特征。概述必须覆盖两张图，不可只写其中一张。

6. Process Diagram（流程图）

写作流程

  1. 判断自然过程还是人工过程；

  2. 找起点、终点和阶段数；

  3. 概述整体过程；

  4. 按箭头顺序描述；

  5. 人工流程通常多用被动语态。

不要解释流程背后的原因，也不要遗漏回路或分支。

7. Maps（地图题）

先确定时间变化、方位和未变化区域；概述最显著变化；细节段可按区域或变化类型分组。

常见变化：建造、拆除、扩建、改造、搬迁、道路连接和功能替换。

十二、General Training Writing Task 1

培训类 Task 1 通常是书信。首先判断对象和关系，再确定正式、半正式或非正式语气。

1. Formal Letter（正式信）

适用：机构、公司、政府部门或陌生负责人。

流程：说明写信目的；逐项回应题目要求；提出期望行动；礼貌结束。避免缩写和过于口语化的表达。

2. Semi-formal Letter（半正式信）

适用：认识但关系不亲密的人，如房东、老师、同事。语气礼貌但不必过度正式。

3. Informal Letter（非正式信）

适用：朋友或家人。可以使用自然口语、缩写和个人情感，但仍需完整回应所有任务点。

书信检查

  • 是否回应每个 bullet point；

  • 语气是否符合关系；

  • 写信目的是否在开头清楚说明；

  • 请求、解释、道歉或建议是否具体；

  • 结尾是否合适。

十三、Writing Task 2 大作文

无论学术类还是培训类，都需要针对社会、教育、科技、环境等话题写议论文。基础考生应优先保证立场明确、段落清楚、例子相关。

通用四段结构

  1. 引言：改写题目并回应任务；

  2. 主体段一：中心句、解释、例子、回扣；

  3. 主体段二：中心句、解释、例子、回扣；

  4. 结论：总结立场，不加入新观点。

1. Agree or Disagree（同意与否）

开头明确完全同意、完全不同意或部分同意。主体段必须持续支持这一立场，不能前后摇摆。

2. Discuss Both Views and Give Your Opinion

一段解释观点A，一段解释观点B，并在引言和结论明确自己的观点。不要只罗列双方理由而忘记个人立场。

3. Advantages and Disadvantages

先确认题目是否要求判断利大于弊。普通优缺点题可分别讨论；若问是否利大于弊，必须明确比较和结论。

4. Problems and Solutions / Causes and Solutions

问题、原因、影响和解决办法不能混写。解决办法必须针对前文提出的具体问题或原因。

5. Two-part Questions（双问题）

题目包含两个直接问题。建议两个主体段分别回答，并确保篇幅相对平衡。

6. Positive or Negative Development

明确判断这一趋势整体积极还是消极，再用两个主要理由证明。可以承认另一面，但不能削弱最终立场。

十四、写作保姆级练习法

第一步：句子训练

每天写5个正确句子，重点练原因、结果、比较、让步和举例。先保证主谓一致、时态、冠词和单复数。

第二步：段落训练

每次只写一个主体段：

中心句 → 解释原因 → 具体例子 → 回扣题目

检查每句话是否服务于中心句。

第三步：提纲训练

每天选择一道题，用5分钟写：立场、两个主要理由、每段例子。不会展开通常不是语言问题，而是观点不具体。

第四步：完整作文

先不计时完成，再逐渐进入限时。写完后必须修改一遍，不能只交给批改工具就结束。

写作自查清单

  • 是否回答了题目所有部分；

  • 立场是否明确且一致；

  • 每段是否只有一个中心；

  • 例子是否具体且相关；

  • 是否有机械模板句；

  • 是否重复同一个词；

  • 是否存在主谓、时态、冠词和单复数错误；

  • 结论是否加入新观点。

每天60分钟写作方案

  • 10分钟：复习主题词和错误句；

  • 10分钟：分析一道题并列提纲；

  • 25分钟：写一个主体段或 Task 1；

  • 15分钟：检查、修改并重写问题句。

第四部分：口语 Speaking

口语考试分三部分。训练目标不是背出完美答案，而是自然、清楚、持续地表达，并让词汇、语法和发音足以支持内容。

十五、口语通用训练流程

每个问题按以下顺序练习：

  1. 第一次直接回答并录音；

  2. 回听，记录停顿、重复、语法和发音问题；

  3. 补充观点、原因和例子；

  4. 重组关键词，不写整篇背诵稿；

  5. 第二次重新录音；

  6. 第二天换一种说法再答一次。

不要先写中文再逐句翻译。建立“英文关键词 → 英文句子”的反应方式。

十六、Speaking Part 1

Part 1 主要讨论熟悉的个人话题。

常见话题

  • 工作与学习；

  • 家乡与居住地；

  • 兴趣爱好；

  • 日常习惯；

  • 食物、天气、交通；

  • 购物、手机、互联网；

  • 朋友、家庭和周末活动。

答题结构

直接回答 → 给出原因 → 补充一个细节或例子

示例逻辑：

Yes, I do. The main reason is that... For example...

不是每一题都必须严格套模板。通常回答2～4句即可，避免只说 Yes 或 No，也不要讲成两分钟演讲。

训练步骤

  1. 每天选择一个主题；

  2. 回答5～8个问题；

  3. 第一遍不看稿录音；

  4. 回听并修改最明显的错误；

  5. 用关键词第二次作答；

  6. 把可复用表达加入个人素材库。

常见问题

  • 背诵痕迹明显；

  • 所有回答都使用同一结构；

  • 为了用难词而表达不自然；

  • 一直使用 very good、very interesting；

  • 回答过短，无法展示语言能力；

  • 回答过长，偏离问题。

十七、Speaking Part 2

Part 2 根据话题卡进行个人陈述。考前准备时间用于写关键词，不要写完整句子。

通用准备框架

在草稿上快速记录：

  • Who / What：人物或事物；

  • When / Where：时间和地点；

  • What happened：经过；

  • Why important：原因；

  • Feeling / Result：感受和结果。

通用表达结构

  1. 开头直接说明要讲什么；

  2. 交代背景；

  3. 按时间或逻辑展开细节；

  4. 说明感受、影响或意义；

  5. 用一句话自然收尾。

1. 人物类

可以准备家人、朋友、老师、同事和公众人物。内容包括如何认识、性格特点、具体事件和对自己的影响。

2. 地点类

可以准备城市、公园、商店、餐厅、自然景点和安静场所。内容包括位置、外观、活动、一次经历和喜欢原因。

3. 物品类

可以准备礼物、书、照片、电子产品、衣服和旧物。内容包括来源、外观、用途、使用经历和意义。

4. 经历与事件类

可以准备旅行、挑战、成功、等待、帮助别人、聚会和重要决定。按起因、过程、结果和感受展开。

5. 活动与技能类

可以准备运动、爱好、学习技能、工作任务和未来计划。说明何时开始、如何学习、困难、收获和未来安排。

素材复用

一个真实经历可以改编到多个题目。例如一次旅行可以用于有趣地点、难忘经历、照片、朋友、交通和天气话题。复用经历，不等于背诵完全相同的答案。

防止讲不满的方法

增加具体细节：时间、地点、人物、对话、困难、转折、结果和感受。不要用大量空洞形容词拖延时间。

十八、Speaking Part 3

Part 3 更重视抽象观点、原因分析、比较和社会层面的讨论。

常见问题类型

1. 原因题

结构：主要原因 → 解释机制 → 例子。

2. 影响题

可以从个人、家庭、社会、经济和环境角度分析，但每次选择最相关的两个角度即可。

3. 比较题

明确比较对象和维度，如过去与现在、年轻人与老年人、城市与农村。不要只分别描述两者。

4. 优缺点题

先表明总体判断，再讨论主要优点和缺点。时间有限时，不需要追求绝对平衡。

5. 解决办法题

指出谁应该行动、采取什么措施，以及为什么有效。避免只说政府应该重视。

6. 未来预测题

给出趋势判断、原因和可能结果。可以使用 may、might、is likely to，避免把不确定预测说成事实。

Part 3 回答框架

观点 → 原因 → 解释 → 例子／比较 → 小结

基础较弱时先保证一个观点讲清楚，再增加第二个观点。

十九、口语发音与流利度训练

跟读流程

  1. 选择30～60秒清晰录音；

  2. 先听懂大意；

  3. 看文本标记停顿和重音；

  4. 分句模仿；

  5. 尝试与录音同步；

  6. 录下自己并进行对比。

优先改进

  • 单词重音；

  • 句子重音；

  • 结尾辅音；

  • 常见连读；

  • 意群停顿；

  • 语速稳定。

不必刻意模仿某种口音。清楚、稳定、容易理解比口音更重要。

第五部分：全科基础系统

二十、全科词汇怎么背

不要只背一本长词表。词汇分成四类管理：

1. 识别词汇

阅读和听力中看到或听到能理解即可。重点积累同义替换、词族和常见搭配。

2. 拼写词汇

听力填空中必须准确写出的词，如月份、星期、地点、职业、设施和常见学术词。

3. 输出词汇

写作和口语中自己真正会使用的词。每个词至少掌握一个自然搭配和一个自己的例句。

4. 逻辑词汇

表示转折、因果、比较、让步、举例和程度的词，直接影响四科理解与表达。

二十一、语法学习顺序

第一层：先保证句子正确

  • 主谓一致；

  • 基本时态；

  • 名词单复数；

  • 冠词；

  • 代词指代；

  • 基本介词。

第二层：理解和使用复杂句

  • 定语从句；

  • 状语从句；

  • 名词性从句；

  • 非谓语动词；

  • 被动语态；

  • 比较与让步结构。

第三层：提升自然度

  • 长短句结合；

  • 避免连接词堆积；

  • 使用准确搭配；

  • 减少中式表达；

  • 学会改写同一意思。

语法学习必须回到真实题目：阅读中拆句，听力中检查填空语法，写作中修改错句，口语中重复正确表达。

二十二、在职每周学习表

每天约60分钟版本

工作特别忙的最低任务

每天只做以下三件事也可以保持状态：

  1. 复习10分钟词汇；

  2. 完成一道错题复盘；

  3. 精听或开口10分钟。

重点是不断线，而不是某一天学很久后连续几天停止。

二十三、每周复盘会议

每周固定20～30分钟回答：

  1. 本周各科学习了多少分钟？

  2. 哪个题型错误最多？

  3. 哪类错误反复出现？

  4. 哪些词已经多次遇到仍不认识？

  5. 哪种写作问题最明显？

  6. 口语最大问题是内容、停顿、语法还是发音？

  7. 下周只解决哪两个核心问题？

二十四、模拟考试流程

第一次整套模拟前

  • 已分别练过主要题型；

  • 已完成单部分计时；

  • 知道自己的时间分配；

  • 有稳定的跳题规则；

  • 能使用检查清单。

模拟当天

  1. 使用未做过的正式材料；

  2. 关闭消息提醒；

  3. 严格计时，不暂停；

  4. 完整记录答案；

  5. 记录每部分结束时间；

  6. 模拟结束后休息，再进行复盘。

模拟后不要只看总分

分别统计：

  • 哪个 Section 或 Passage 最弱；

  • 哪种题型最弱；

  • 错误来自能力还是时间；

  • 哪些题本来会做但因流程失分；

  • 下周应该减少什么、增加什么。

二十五、考前最后14天

第14～8天

  • 完成2～3次完整模拟；

  • 针对重复错误补练；

  • 固定写作结构和口语素材；

  • 回顾高频拼写和同义替换。

第7～3天

  • 减少新题和新资料；

  • 重做高价值错题；

  • 保持听力输入和口语输出；

  • 完成少量限时训练，维持节奏。

最后2天

  • 不进行高强度刷题；

  • 复习流程、检查表和个人常错词；

  • 确认考试安排和所需证件；

  • 保持正常睡眠和饮食。

二十六、完整备考检查清单

听力

  • 会预测词性和答案类型；

  • 能识别改口和干扰项；

  • 地图题能确认起点和方向；

  • 会在漏题后迅速继续；

  • 有个人拼写错误清单。

阅读

  • 会根据题型决定阅读顺序；

  • 每道题能找到证据；

  • 能区分 FALSE 与 NOT GIVEN；

  • 能概括段落主旨；

  • 会在难题上及时止损。

写作

  • 能快速识别题型；

  • 能在5分钟内完成提纲；

  • 每段只有一个清楚中心；

  • 例子能支持观点；

  • 留有检查时间；

  • 不依赖背诵整篇模板。

口语

  • Part 1 能自然回答2～4句；

  • Part 2 能用关键词持续展开；

  • Part 3 能说明原因和例子；

  • 停顿时能自然恢复；

  • 有个人素材库而不是背诵稿；

  • 定期录音并重答。

二十七、最重要的执行原则

  1. 基础阶段先正确，再提速。

  2. 每次练习必须复盘。

  3. 词汇要结合发音、搭配和真题语境。

  4. 写作和口语必须真实输出。

  5. 一次重点解决一两个问题。

  6. 使用数据调整计划，不凭焦虑增加任务。

  7. 每天少量持续，优于周末一次突击。

真正有效的备考，不是做完最多的材料，而是不断减少重复错误。
